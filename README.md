# Friend Forge

**Friend Forge** is an interactive Rare Friends game prototype built for the Rare Friends Vibeathon.

You control a Friend on an isometric island, collect Ore, forge randomized artifacts, and build a Collection.

> Current build: **v0.2.4 — standalone playable prototype**  
> FriendSDK integration is the next milestone.

## Playable Preview

GitHub Pages URL after deployment:

`https://YOUR_GITHUB_USERNAME.github.io/friend-forge/`

## Current Gameplay Loop

1. Walk around the island with WASD / arrow keys or click/tap.
2. Click a building label to auto-navigate to it.
3. Visit **Ore Mine**.
4. Spend demo RF to buy Ore.
5. Visit **Central Forge**.
6. Spend 1 Ore to forge a randomized artifact.
7. Reveal the artifact.
8. Open **Collection** to view discoveries and duplicates.

## Buildings

- **Ore Mine** — converts demo RF into Ore.
- **Central Forge** — converts Ore into random artifacts.
- **Collection** — stores discovered artifacts and duplicate counts.
- **Reforge** — currently preview-only.
- **Community Furnace** — currently preview-only.

## Artifact Rarities

| Rarity | Total chance |
|---|---:|
| Common | 50% |
| Uncommon | 27% |
| Rare | 14% |
| Epic | 6% |
| Legendary | 2.5% |
| Mythic | 0.5% |

There are currently 12 artifact outcomes.

## Controls

- `WASD` — move
- Arrow keys — move
- Click/tap ground — move to destination
- Click building label — auto-navigate around colliders and open its menu

## Current Prototype Notes

This version is still a standalone browser prototype.

- RF balance is simulated.
- Ore and Collection state are local prototype state.
- Forge randomness currently uses browser Web Crypto.
- Reforge and Community Furnace are not active yet.
- FriendSDK wallet / NFT ownership flow is not integrated yet.

The next milestone is to migrate the game to **FriendSDK v0.1.2**, replacing local economy state with SDK actions and using the selected Generations NFT as the playable Friend.

## Planned FriendSDK Integration

The SDK version will use:

- wallet connection and Robinhood mainnet network flow;
- owned Rare Friend selection;
- `friendId` as the playable character identity;
- SDK `buy()` for Ore;
- SDK `play()` and `settle()` for Forge outcomes;
- SDK snapshot state instead of browser-local economy state;
- public static build generated by FriendSDK;
- GitHub Pages for the playable preview.

## Local Preview

For the current standalone build you can simply open:

```text
index.html
```

in a browser.

A local static server is preferred if your browser limits local-file behavior:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## GitHub Pages — Current Standalone Build

For the current v0.2.4 prototype:

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose:
   - Branch: `main`
   - Folder: `/(root)`
5. Save.
6. Wait for the deployment to finish.
7. Open:

```text
https://YOUR_GITHUB_USERNAME.github.io/friend-forge/
```

## GitHub Pages — After FriendSDK Integration

FriendSDK generates a static build in:

```text
games/friend-forge/.friendsdk/
```

At that stage GitHub Pages should no longer publish the source root.

The generated `.friendsdk/` contents will be copied to the root of a dedicated `gh-pages` branch, including:

- `index.html`
- `game.html`
- generated JavaScript
- generated CSS
- assets
- `.nojekyll`

Then GitHub Pages will be configured as:

- Branch: `gh-pages`
- Folder: `/(root)`
